## 🚀 Welcome to the Future of AI Education

A comprehensive, beginner-friendly, project-driven curriculum on **Generative AI** and **Retrieval-Augmented Generation (RAG) Agents**. Learn core concepts like prompt engineering, vector embeddings, chain orchestration, and building intelligent chat agents through clear, hands-on examples.

### 🎯 What You'll Master
- **Generative AI Fundamentals** - Understanding LLMs and their capabilities
- **Prompt Engineering** - Crafting effective prompts for optimal results
- **RAG Systems** - Building intelligent retrieval-augmented applications
- **Vector Databases** - Working with embeddings and semantic search
- **AI Agents** - Creating autonomous intelligent systems
- **Production Deployment** - Taking your AI apps from prototype to production

## 🛠️ Prerequisites & Setup

### System Requirements
- **Operating System**: Windows, macOS, or Linux
- **Python**: 3.8 or higher
- **Node.js**: 16 or higher (for some examples)
- **Git**: For cloning and version control

### Quick Start
```bash
# Clone the repository
git clone https://github.com/hereandnowai/generative-ai-for-beginners-project-based-guide-to-building-rag-agents.git

# Navigate to the project directory
cd generative-ai-for-beginners-project-based-guide-to-building-rag-agents

# Install Python dependencies
pip install -r requirements.txt

# Install Node.js dependencies (if needed)
npm install

# Start with lesson 00 for environment setup
cd 00-course-setup
```
